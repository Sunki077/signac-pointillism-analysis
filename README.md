# 点彩视觉机制分析 —— 保罗·西涅克《阿维尼翁傍晚》

本仓库包含艺术史研究论文《点彩视觉机制研究：以保罗·西涅克〈阿维尼翁傍晚〉为中心的计算与艺术史分析》所用的图像分析代码。

## 生成的分析图
- 图1：原始图像
- 图2：LAB色彩聚类（主色结构）
- 图3：边缘检测（点彩结构近似）
- 图4：视觉密度热力图
- 图5：多尺度高斯模糊（光学混色模拟）
- 图6：Sobel梯度（潜在构图结构）

## 依赖库
请先安装以下 Python 库：
```bash
pip install opencv-python numpy matplotlib scikit-learn scikit-image scipy
```
## 文件说明
signac_avignon.jpg – 输入图像（请放入自己的高清图片并命名为该文件名）

analysis.py – 主脚本，运行后生成所有分析图

figures/ – 输出目录，生成的图片将保存在此

## 使用方法
将图像文件命名为 signac_avignon.jpg 放在与脚本相同的文件夹中

运行脚本：

```bash
python analysis.py
```
输出图片将保存在 figures/ 文件夹中，格式为 PNG + SVG

## 方法参数摘要
| 图号 | 方法 | 关键参数 |
| --- | --- | --- |
| 图1 | 原始图像（显示） | 无 |
| 图2 | LAB空间 k-means 聚类 | 聚类数 k=6, n_init=10 |
| 图3 | Canny 边缘检测 | sigma=2 |
| 图4 | 边缘密度热力图（高斯滤波） | sigma=15 |
| 图5 | 多尺度高斯模糊（模拟不同观看距离） | sigma=2（近距）, sigma=5（中距）, sigma=10（远距） |
| 图6 | Sobel 梯度幅值（构图结构提取） | dx=1, dy=1 |
